# Daily Log — 30 July 2026

Session focused on trustworthiness of the v1 NL weather-analytics app: making point statistics
exactly match the raw dataset, benchmarking the app against other AI tools, verifying every answer
with the app itself, and adding compound-question handling. Also produced a report reading list.

## What was done

### Exact numbers on the native grid
Routed max/min/mean/spread through the raw 10-minute frame (not the hourly mean), so "highest
temperature in July 2015" now returns the true 37.28 °C. Confirmed with a 3-level oracle
(app pipeline vs independent pandas vs raw CSV bytes).

### Transparent natural-language handling
High-confidence typo auto-correction (shown to the user), a gray-zone "did you mean?" guardrail for
near-miss words, best-guess assumption notes when a sensor/statistic/period had to be assumed, and a
general ask-again fallback for any not-understood query.

### Answer two questions at once (compound questions)
"max temperature in 2015 AND min humidity in 2013" is now split and answered as two independently
scoped sub-answers, instead of silently answering only the first with a merged scope. Correlation,
compare, and "between X and Y" ranges are deliberately NOT split.

### External-LLM benchmark (other AI as the baseline)
Like-for-like contest — same question, same in-prompt data, scored against an independent oracle:
- **Local Ollama**: our app 8/8; Gemma-4-E4B 6/8 (missed both means); llama3.2 1/8; Gemma-3-1B 0/8.
- **OpenRouter free tier**: our app 8/8; nemotron-120b 8/8; ling-3.0-flash 8/8; nemotron-550b 7/8
  (one API error); gpt-oss-20b 6/8; gemma-4-31b 1/8 (rate-limited).
- **Routing/understanding** (49 hand-labelled questions): our app 100% vs ling-3.0-flash 53%.
- Commercial tools (ChatGPT/Kimi/GLM) have a generated manual pack (upload-CSV + ask). No paid
  credit used; a nemotron-120b routing run was excluded (free daily quota → all 429s).

### App-as-verifier
`verify_benchmark.py` confirms the app is a correct reference: app == oracle on all 8 gold answers,
and re-grading every contestant with the app reproduces the oracle grades with ZERO disagreements
(9 contestants); app routing == hand-labelled truth (100%).

## Key findings
- With the data in the prompt, capable hosted LLMs CAN match the app on computation (incl. means);
  tiny local models cannot. The app's edge over strong models is being exact AND instant AND
  reliable AND offline — the hosted runs showed a malformed API response, a 477 s latency spike, and
  rate-limit wipeouts.
- On understanding (routing), the same model that scored 8/8 on computation gets only ~53% —
  systematically confusing single-sensor "summary" with whole-day "weather". Deciding what a messy
  question asks is where the purpose-built parser wins. (Honest caveat: the app's 100% is flattered
  by parser/ground-truth co-evolution; the independent gap is the real signal.)
- Dataset gotchas pinned down: 183 duplicate timestamps in 2014 (dropped keep-first); means computed
  on the full 10-min grid, not a mean-of-hourly-means.
